### 公园
从东门进,门口一路上去就是猴子和动物园,还有弘福寺背后往坐缆车下山的那座山全是猴子!如果怕猴子,就别把吃的露出来让他看到,如果他硬要抢,要么给他,要么就凶一点,你越躲他,他越要扒拉你
